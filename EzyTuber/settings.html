⚙️ Ezy Tuber

Thay đổi được áp dụng và lưu ngay.
Cỡ model được lưu riêng cho từng model.
Mỗi thư mục con trong thư mục model là một model. Bấm Import model và chọn file .zip (hoặc kéo thả file .zip vào tab này): app tự tìm đúng thư mục chứa model trong zip, bỏ file thừa, kiểm tra rồi đưa vào thư mục model. Làm thủ công: xem model/README.txt.
Bấm vào ô phím rồi nhấn tổ hợp phím muốn dùng để chuyển nhanh sang model đó (kể cả khi đang chơi game). Esc = huỷ, Backspace = xoá phím.

😀 Biểu cảm & Emote:

Bấm vào ô phím rồi nhấn tổ hợp phím để gán (dùng được cả khi đang chơi game). Phím biểu cảm: bấm lần nữa để quay về mặc định. Phím emote: bật/tắt. Mỗi model có bộ phím riêng.

🎛️ Tinh chỉnh chuyển động:

Kéo là thấy model đổi ngay và tự lưu, riêng cho model này. Nút ↺ trả một thanh về mặc định.
